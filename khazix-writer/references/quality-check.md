# 写完之后的四层检查

初稿写完再读这份文件。四层从最硬的规则查到最主观的感觉，前一层没过就先改。

所有的风格手法都不设数量指标。不为了凑一处自嘲、一个口头禅或一段叙事去补造内容。用户定的篇幅、身份和事实边界，优先于下面任何一条风格要求。

## 第一层 硬性规则

这一层可以逐条搜，搜到就改，没有例外。

**禁用词。** 全文搜下面这些，出现就换掉：

- "说白了" → "坦率的讲"、"其实就是"
- "意味着什么" / "这意味着" → "那结果会怎样呢"、"所以呢"
- "本质上" → "说到底"、"其实"
- "换句话说" → "你想想看"、"也就是说"
- "不可否认" → 删掉，直接正面陈述
- "综上所述" / "总的来说" → 换成一句具体的回扣
- "首先...其次...最后" → 用自然的转场
- "值得注意的是" / "不难发现" → 删掉，直接说

**禁用标点。**

- 冒号"：" → 用逗号。网址、时间、比例、代码和 Prompt 原文里的不动，引出一句原话或金句的可以留
- 破折号"——" → 用逗号或句号
- 双引号""和"" → 用「」，或者不加引号

这些标点在修改过程中很容易被重新带进来，全部改完后再搜一遍。

**结构性套话。**

- "让我们来看看..." / "接下来让我们..."
- "在当今...的时代" / "随着...的发展"
- 用 bullet point 罗列观点。出现了就改成一段话讲
- 大段加粗

**空泛的名字。** AI 工具和产品都写具体的名字，不出现"AI工具""某个模型""相关技术"。

**编造。** 第一人称的经历、实测、购买、对话，逐处对一下是不是用户给的。不是就删掉，或者换成待补标记。数字、日期、引语有没有来源。

## 第二层 风格

逐段读，看它像不像卡兹克在说话。

**开头。** 是不是从一个具体的、当下的事件或场景切入？第一句话会不会让人想问"然后呢"？有没有教科书式的开场？

**节奏。** 句子有没有长短变化？连着好几句一样长，读起来就呆。关键的地方有没有用一句话单独成段让它停一下？岔出去讲完一个案例或背景，后面有没有一句话拉回主线？有没有用疑问句给读者一个刹车和转向？同一组数字、同一个结论有没有讲了好几遍？结尾是不是只收了一次？

**结构。** 除了"N条心得"这种分条目的文章，有没有出现 markdown 标题或加粗小标题？有就去掉，换成口语化的转场。

**口语。** 读起来像在聊天，还是像在写报告？像报告的段落，用他常用的说法重写。有没有论述中的故意打破，重复强调、中途打断、省略主语。

**照搬。** 有没有把示例库里的典故和经历搬过来？《北京折叠》、1880 年代的电力史、格式塔心理学、示例文章里的个人经历和已经过时的模型名，出现了就换成这篇文章自己的材料。

**密度。** 两头都要查。口头禅、粗口、"。。。"和"？？？"是不是太密了？同一个口头禅有没有反复出现？有没有整句搬了示例库里的原话？密到像在表演，就删掉一半。反过来，是不是收得太紧，读着像一篇工整的专栏？连着的排比、对仗的格言句、每段末尾的金句，拆掉，换成聊天时会说的话。

## 第三层 内容

**观点有没有东西托着。** 每个核心观点都有具体的人、场景、细节或数据吗？只有论断没有例证的，补材料或者删掉这个观点。

**知识是不是顺手掏出来的。** 有没有"下面我来介绍""首先需要了解"这种科普腔？引用的论文、书、历史，是聊着聊着想起来的感觉，还是特意去查的感觉？

**升维自不自然。** 文章从具体的事连到更大的文化、哲学或历史参照物时，是材料里长出来的，还是硬贴上去的？硬贴的删掉。没有合适的升维就不升，一篇把事情讲透的文章不需要强行拔高。

**有没有站到对面看过。** 讲核心观点时，有没有先理解和承认对方的处境，再给自己的视角？

**文章类型该有的东西。**

- 调查实验型：有没有亲自下场的过程？发现是不是一层层递进的？
- 产品体验型：有没有真实的使用场景？和其他产品的对比是不是自然带出来的？
- 现象解读型：有没有"观察→好奇→研究→升维"的推进？
- 工具分享型：有没有个人故事铺垫？效果展示有没有让人"卧槽"的地方？
- 方法论分享型：每一节有没有落到今天就能做的动作？有没有坦诚说学习成本和失败点？开头结尾有没有卸掉"我来教你"的姿态？

**多个案例的排法。** 涉及多个产品或案例的对比时，是逐个展示、每个带一句点评，还是一次性列结论？顺序是不是从弱到强，最炸的留在最后？

## 第四层 活人感

最后以读者的身份从头到尾读一遍，回答一个问题：

**读完这篇文章，我感觉是一个有见识的普通人在认真跟我聊一件打动他的事，还是一个AI在给我输出信息？**

读的时候留意：

- **温度。** 情绪是体感记忆（"我当时就愣住了""鼻子一酸"），还是知识性描述（"我感到非常震撼"）？写到人的时候，这个人立得起来吗？
- **独特。** 这篇有没有只有这个作者才会写出来的角度？换一个AI博主是不是也能写出差不多的东西？
- **姿态。** 有没有不知不觉滑进"导师在教学生"或"品牌在做营销"的口气？
- **心流。** 读到哪里注意力断了、需要回头理一下逻辑？那个地方就是节奏有问题。

哪一段让你觉得AI味重，就把它找出来，想象卡兹克本人会怎么说这段话，用更口语、更私人、更不完美的方式重写。这一层没有机械的修法。
